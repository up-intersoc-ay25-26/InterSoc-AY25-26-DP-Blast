# InterSoc DP Blast Website
Welcome! This is the official DP Blast Website.
Originally Developed by Brian Pangue.

This version of the website accommodates previous academic years (starting from AY 2024-2025). 

## To update:
1. Run `git clone git@github.com:UPTAC-KomSai-v2/InterSoc-DP-Blast.git` to your preferred directory.
2. Run `npm install` to install all packages from the packages json.
3. Add a new academic year to the academic_years variable in `scripts.js` and the new AY's caption in `captions.js`.
4. Create a new folder inside `src/images/frames` corresponding to the AY you're making the DP for and add the frames there.

## To deploy using Github Pages:
Inside your Github repo:
1. Proceed to Settings
2. Click on Pages
3. Change the branch from None to the AY202X-202Y
4. Click save
