# InterSoc DP Blast website
Before deploying, make sure to `git clone` the repo, create the branch corresponding to its AY through `git checkout -b AY202X-202Y`, publish it, and update all instaces of the academic year in the files.
Upload the new DP frame for the DP blast inside the `src/images` directory.

To deploy:
1. Proceed to Settings
2. Click on Pages
3. Change the branch from None to the AY202X-202Y
4. Click save

Github Pages will deploy the DP Blast static site.
