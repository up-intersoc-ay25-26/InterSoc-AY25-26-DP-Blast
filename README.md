# InterSoc DP Blast Website
Welcome! This is the official DP Blast Website.
Originally Developed by Brian Pangue.

Before deploying, make sure to `git clone` the repo, create the branch corresponding to its AY through `git checkout -b AY202X-202Y`, and publish the branch to remote.

Run `npm install` to install all packages from the packages json, then update all instances of the academic year in the files.

Lastly, upload the new DP frame for the DP blast inside the `src/images` directory.

## To deploy using Github Pages:
Inside your Github repo:
1. Proceed to Settings
2. Click on Pages
3. Change the branch from None to the AY202X-202Y
4. Click save
